## Возможности

- Игровое поле 4×4 со случайным появлением плиток.
- Движение и последовательное слияние одинаковых плиток с подсчетом очков.
- Управление стрелками на компьютере и свайпами на мобильных устройствах.
- Плавные анимации движения, появления и слияния плиток.
- Отмена последнего хода и начало новой игры.
- Сохранение игрового поля, счета и предыдущего хода в localStorage.
- Определение окончания игры и сохранение результата с именем игрока.
- Таблица топ-10 результатов с именами, очками и датами.
- Адаптивная верстка для компьютеров, планшетов и смартфонов.

## Технологии

HTML, CSS и JavaScript без фреймворков. Для верстки используются Flexbox, Grid и медиазапросы. Игровая сетка создается через DOM API, анимации реализованы с помощью Web Animations API.

## Правила игры

Перемещайте плитки в одну из четырех сторон. Одинаковые значения объединяются, а результат слияния добавляется к счету.

По условию лабораторной слияния могут продолжаться в рамках одного хода. Например, четыре плитки со значением 4 превращаются в одну плитку 16 и приносят 32 очка.

После успешного хода на свободной клетке появляется новая плитка со значением 2 или 4. Игра заканчивается, когда больше нет возможных движений. После окончания игры отмена хода недоступна.

## Структура проекта

- `index.html` - разметка страницы и модальных окон.
- `css/style.css` - оформление игры и адаптивность.
- `css/animations.css` - расположение слоя движущихся плиток.
- `css/dialogs.css` - оформление окон окончания игры и рекордов.
- `js/app.js` - игровая логика, анимации, сохранение состояния и таблица рекордов.
- `js/swipe.js` - управление свайпами.
- `favicon.svg` - иконка вкладки со снежинкой.

## Локальный запуск

Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server.
